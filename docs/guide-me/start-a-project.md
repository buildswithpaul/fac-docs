# Guide me: start a project

A project keeps one piece of work together: its chats, the instructions FACO follows there, the documents it should know, and what it remembers. Here, a project for renewing a customer's supply contract.

**You need:** FAC Chat. Project documents and project memory also need an up-to-date FAC Cloud.

## 1. Make the project

In the FAC Chat sidebar, click **+** next to **Projects**, type a name and press **Enter**.

![Naming a new project in the sidebar](/img/guide-me/project-new.webp)

The project page opens: chats on the left, the project's context on the right.

![A new, empty project page](/img/guide-me/project-page.webp)

## 2. Tell FACO how to work here

Under **Instructions**, click **Edit**, write how FACO should work in this project and click **Save**. Every chat in the project follows them.

![Project instructions saved](/img/guide-me/project-instructions.webp)

## 3. Add the documents it should know

Under **Documents**, click **Upload** and choose a file. It shows **Processing**, then **Ready** once FACO can read it. Only you can see a project's documents.

![The supply agreement uploaded and ready](/img/guide-me/project-document.webp)

## 4. Ask inside the project

Type into the box at the top of the project page. It says *"Uses this project's instructions, documents and memory"*, and that is what FACO brings to the chat.

![Asking a question from the project page](/img/guide-me/project-ask.webp)

FACO reads the documents and checks ERPNext together. Here it took the contract's end date and renewal clause from the uploaded agreement, the invoices from ERPNext, and kept the answer short and in ₹ lakh, as the instructions asked.

![The answer, combining the contract and ERPNext](/img/guide-me/project-answer.webp)
