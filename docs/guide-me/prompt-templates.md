# How to use a prompt template

A prompt template is a saved question with blanks. Pick one, fill in the blanks and send. It saves you writing a long, careful request each time.

**You need:** FAC Chat. Templates are managed by an administrator in [FAC Admin](/guides/prompt-templates).

## 1. Type / in the message box

A menu lists the templates you can use. Arrow keys move, **Enter** picks one, and **Browse all** opens the full list. The **+** button in the message box opens the same list.

![The template menu after typing a slash](/img/guide-me/templates-slash.webp)

## 2. Browse and pin

**Quick Prompts** shows every template with its category. Search, filter by category, and click the star to pin the ones you use most. Click **Use**.

![The Quick Prompts browser](/img/guide-me/templates-browser.webp)

## 3. Fill in the blanks

Each template asks only for what it needs. This one, **Sales Analysis**, asks what to focus on and which period.

![A template's blanks filled in](/img/guide-me/templates-params.webp)

## 4. Send

Click **Use**. The full request is placed in the message box, so you can read or edit it before you press **Enter**.

![The answer to the Sales Analysis template](/img/guide-me/templates-answer.webp)

## Use cases

| You want to | Template and blanks | What happened on the demo site |
|---|---|---|
| A quarterly review of customers | **Sales Analysis**, focus *customer_analysis*, period *last_quarter* | A full review: headline numbers against the previous quarter, top customers, lapsed customers, overdue invoices and eight recommendations. It ran 18 steps and used 186 credits |

The other templates that ship with FAC work the same way: CRM Analysis, Data Quality Audit, DocType Documentation Generator, HR Analysis, Manufacturing Analysis and Purchase Analysis.

A broad template such as this one reads a lot of data, so it costs more than a plain question. Narrow the focus and the period when you can.

**More:** [Prompt Templates](/guides/prompt-templates) covers writing and sharing your own.
