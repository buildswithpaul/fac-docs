# How to choose how FACO loads its tools

FACO has many tools. By default it loads only the ones a conversation needs and adds more as the conversation calls for them, for example the import tools when you attach a spreadsheet. You can switch that off for yourself.

**You need:** FAC Chat and an up-to-date FAC Cloud.

## Change the setting

In FAC Chat, open **Settings → Tools**. **Load tools as needed** is on by default. Switch it off to give FACO every tool on every message.

![The Tools setting](/img/guide-me/tools-setting.webp)

The choice is yours alone; other users keep their own.

## Use cases

| Situation | Setting |
|---|---|
| Everyday questions and tasks | Leave **Load tools as needed** on |
| FACO says it has no tool for something you know it can do | Switch it off for that chat, then tell us with [Report this](./rate-answers) |
