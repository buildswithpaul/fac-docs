# How to rate an answer or report a failed one

Tell us when FACO gets something wrong. A rating takes one click and is linked to the answer's usage record (model, time and credits), not to what you wrote.

**You need:** FAC Chat and an up-to-date FAC Cloud.

## 1. Rate an answer

Every finished answer has a 👍 and a 👎 under it. A 👎 asks what went wrong. Pick a reason, add a note if you like, and click **Send**.

![The reasons shown after a thumbs down](/img/guide-me/feedback-reasons.webp)

## 2. Answer the occasional check-in

Now and then, at most once a fortnight, a small card asks **How is FACO doing for you?** Click a number from 1 to 5, or close the card.

![The How is FACO doing card](/img/guide-me/feedback-pulse.webp)

## 3. Report an answer that did not finish

If an answer stops part-way, the chat says so and offers **Retry** and **Report this**.

![An answer that did not finish](/img/guide-me/feedback-failed.webp)

**Report this** opens Help & Feedback with the error already filled in. Add a line about what you were doing, choose whether to include the conversation, and click **Submit**.

![The report form with the error filled in](/img/guide-me/feedback-report.webp)

## Use cases

Each of these was done on the demo site.

| Situation | Do this | What happened |
|---|---|---|
| The answer was right but took too long | 👎, then **Too slow** | The rating was sent with no need to type anything |
| You are asked how FACO is doing | Click a number | The card thanked you and closed |
| An answer stopped part-way | **Report this** | The report form opened with the error code and time filled in |
