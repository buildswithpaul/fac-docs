# Guide me: review a project's memory

As you work in a project, FACO keeps facts that matter to it, such as a customer's contact or a promise made on a call. They stay with that project, apart from your other work, and you can correct them.

**You need:** AI memory switched on (**Settings → Privacy**) and an up-to-date FAC Cloud.

## 1. Open the project

The **Memory** card on the project page lists what FACO remembers for this project. Each item has a label, such as **Fact**.

![The Memory card on a project page](/img/guide-me/memory-card.webp)

## 2. Correct one that is wrong

FACO can get a detail wrong. Here it called a customer's contract a *vendor* contract. Click **Edit** next to it, fix the text and click **Save**.

![Editing a project memory](/img/guide-me/memory-edit.webp)

![The corrected memory](/img/guide-me/memory-saved.webp)

To remove one, click **Delete**. To start the project's memory over, click **Clear project memory**.

## What it is used for

In the project's chats, FACO checks these memories when they help with your question. Your personal memories in **Settings → Memory** stay separate, and deleting a project deletes its memories.
