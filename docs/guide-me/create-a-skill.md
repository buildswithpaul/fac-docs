# Guide me: teach FACO a skill by asking

A skill is written know-how that FACO reads before a task, so it works the way you do. You do not write the file yourself: describe the procedure in chat and FACO creates the skill.

**You need:** FAC Chat and an up-to-date FAC Cloud.

## 1. Describe the procedure

Say what the skill is for and list the steps. Say who should have it: only you, or your team.

> Create a skill called "Credit note checklist" for yourself to follow whenever I ask for a credit note: 1) confirm the original invoice number, 2) check the return was inspected as Good, 3) keep the same tax template as the invoice, 4) show me the draft before submitting. Keep it private to me.

## 2. Approve the card

FACO writes the skill and shows it on an approval card: its name, when it applies, and the full content behind **Show all**. Nothing is saved until you click **Approve**.

![The approval card for a new skill](/img/guide-me/skill-card.webp)

## 3. Read what it will do

FACO confirms the skill is saved, says what it will now do each time, and gives examples of requests that trigger it. The skill is active from your next message.

![FACO confirming the new skill](/img/guide-me/skill-created.webp)

## 4. Use it

Ask for the task as you normally would. FACO loads the skill and follows its steps.

![FACO following the skill's steps](/img/guide-me/skill-used.webp)

## Use cases

Each of these was done on the demo site.

| You ask | What happened |
|---|---|
| The "Credit note checklist" request above | One approval card, then the skill was saved as private. It cost 28 credits |
| "I need a credit note for invoice SINV-26-00020. Walk me through what you will check first" | FACO listed the four steps in order, and tied step 2 to the returns procedure in the Knowledge Base |

Other procedures that suit a skill: how your team names items, what a purchase order needs before approval, or the checks before a month-end close.
