# Guide me: install FAC Chat as an app

Install FAC Chat and it opens in its own window, with its own icon on your dock, taskbar or home screen.

**You need:** Chrome or Edge on a computer, or Safari on an iPhone or iPad.

## On a computer (Chrome or Edge)

1. Open FAC Chat.
2. Click your avatar at the bottom-left and choose **Install app**.

   ![The account menu with Install app](/img/guide-me/install-app.webp)

3. Your browser asks you to confirm. Click **Install**.

FAC Chat opens in its own window. From now on, start it like any other app.

::: tip Don't see Install app?
The item appears only while your browser offers to install FAC Chat. If it is missing, FAC Chat may already be installed, or you may be in a private window, where browsers do not offer to install apps.
:::

## On an iPhone or iPad

Apple's browsers do not offer an install prompt. Choose **Install app** and FAC Chat tells you how: tap **Share**, then **Add to Home Screen**.
